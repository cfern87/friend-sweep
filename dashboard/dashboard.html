Scans to run

Scheduled runs open a Facebook tab and take focus while they scroll, so pick a cadence you won't mind interrupting you. Only scans can be scheduled — removals only ever run when you start them. A run that comes due while another job is going waits for it to finish. Runs only fire while Chrome is open.

Incoming webhooks Pro Beta

Start a scan from anywhere — Zapier, a script, a phone shortcut — by sending a request to your private web address. This browser checks for requests once a minute while Chrome is open, runs them one at a time, and records each one in the activity log. Only scans can be started this way; removals never run remotely.
